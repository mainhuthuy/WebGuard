# Task 1.9 — `Pydantic Schemas` (Chuẩn hoá Dữ liệu & Hợp đồng API)

> **Mục tiêu:** Sử dụng Pydantic v2 để định nghĩa các Data Contracts nghiêm ngặt cho đầu vào (URL validation) và đầu ra (Findings, Score, Response) của WebGuard Scanner.

---

## 📚 Lý thuyết: Pydantic là gì và tại sao cực kỳ quan trọng?

### 1. Vấn đề khi dùng Dictionary tự do:
Nếu một hàm trả về dictionary:
```python
return {
    "url": "https://example.com",
    "findings": [...]
}
```
- Không ai biết bên trong `findings` gồm những trường gì nếu không đọc hết toàn bộ code.
- Nếu một lập trình viên gõ nhầm key `"severty"` thay vì `"severity"`, code vẫn chạy nhưng giao diện frontend sẽ bị vỡ âm thầm!
- Nếu người dùng nhập `"abcxyz"` vào ô URL, scanner sẽ chạy và gây crash hệ thống.

### 2. Pydantic giải quyết triệt để:
- **Type Safety & Data Parsing**: Tự động ép kiểu và xác thực dữ liệu tại Runtime.
- **Fail Fast (Bắt lỗi sớm)**: Nếu dữ liệu đầu vào sai, Pydantic báo lỗi `ValidationError` ngay lập tức tại cổng API trước khi gọi hàm scan tốn thời gian.
- **Tự động sinh tài liệu OpenAPI / Swagger**: Khi đưa vào FastAPI, FastAPI sẽ tự động tạo UI tài liệu API với đầy đủ schema tương tác.

## 📚 Các Schemas Đã Xây Dựng

### 1. `SeverityLevel` (Enum)
```python
from enum import Enum

class SeverityLevel(str, Enum):
    CRITICAL = "critical"
    HIGH = "high"
    MEDIUM = "medium"
    LOW = "low"
```
→ Kế thừa cả `str` và `Enum` giúp Pydantic vừa serialize thành string trong JSON, vừa đảm bảo tính an toàn (chặn các giá trị không hợp lệ như `"urgent"` hay `"warning"`).

### 2. `ScanRequest` (Input Validation)
```python
from pydantic import BaseModel, HttpUrl

class ScanRequest(BaseModel):
    url: HttpUrl
```
- `HttpUrl` tự động xác thực:
  - Bắt buộc phải có protocol hợp lệ (`http://` hoặc `https://`).
  - Phải có tên miền (domain/host) hợp lệ.
  - Tự động chuẩn hoá (ví dụ thêm dấu gạch chéo trailing slash `/` ở cuối).

### 3. `Finding`, `ScoringResult` & `ScanResponse` (Output Data Contract)
```python
class Finding(BaseModel):
    module: str
    name: str
    severity: SeverityLevel
    description: str
    remediation: str
    url: str | None = None

class ScoringResult(BaseModel):
    score: int
    grade: str
    total_findings: int

class ScanResponse(BaseModel):
    url: str
    total_findings: int
    findings: list[Finding]
    scoring: ScoringResult
```
→ Đảm bảo `Scanner.scan()` trả về dữ liệu đúng 100% cấu trúc, sẵn sàng chuyển đổi thành JSON response cho frontend mà không bao giờ lo thiếu trường.
