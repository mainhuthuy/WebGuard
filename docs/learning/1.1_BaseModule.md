# Task 1.1 — Thiết kế `BaseModule` (Abstract Base Class)

> **Mục tiêu:** Tạo lớp trừu tượng làm "khuôn mẫu" cho tất cả module quét bảo mật.

---

## 📚 Lý thuyết: Abstract Base Class (ABC)

### ABC là gì?

ABC (Abstract Base Class) là một lớp **không thể tạo instance trực tiếp**. Nó đóng vai trò như một "hợp đồng" — bắt buộc mọi lớp con phải implement các method được đánh dấu `@abstractmethod`.

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def speak(self) -> str:
        """Mọi con vật phải biết nói"""
        ...

class Dog(Animal):
    def speak(self) -> str:
        return "Gâu gâu"

# ❌ Animal() → TypeError! Không thể tạo trực tiếp
# ✅ Dog()    → OK vì đã implement speak()
```

### Tại sao cần ABC?

Khi có **nhiều module quét** (Headers, Cookies, SSL...), ta cần đảm bảo:
- Tất cả module đều có cùng **interface** (name, description, scan)
- Scanner Orchestrator có thể gọi `module.scan(url)` mà **không cần biết** đó là module gì
- Nếu ai đó tạo module mới mà **quên implement** method → Python báo lỗi ngay

→ Đây là nguyên tắc **Polymorphism** (đa hình) trong OOP.

## 📚 Lý thuyết: Abstract Property

### Property trong Python

`@property` biến method thành thuộc tính — gọi không cần `()`:

```python
class Dog:
    @property
    def name(self) -> str:
        return "Buddy"

d = Dog()
print(d.name)  # "Buddy" — không cần d.name()
```

### Kết hợp @property + @abstractmethod

Để tạo **thuộc tính trừu tượng** (bắt buộc lớp con phải cung cấp giá trị):

```python
@property
@abstractmethod
def name(self) -> str:
    ...
```

> ⚠️ **Thứ tự quan trọng:** `@property` phải ở **TRÊN** `@abstractmethod`. Ngược lại sẽ lỗi!

## 📚 Lý thuyết: Async Method

### Tại sao dùng `async`?

Khi quét bảo mật, ta cần gửi HTTP request đến server. Nếu dùng code đồng bộ (synchronous):

```
Module 1: Gửi request → Chờ 2s → Nhận response
Module 2:                                         → Gửi request → Chờ 2s → Nhận response
Module 3:                                                                                  → Gửi request → Chờ 2s → ...
Tổng: 6 giây 😴
```

Dùng `async` (bất đồng bộ):

```
Module 1: Gửi request → Chờ 2s → Nhận response
Module 2: Gửi request → Chờ 2s → Nhận response
Module 3: Gửi request → Chờ 2s → Nhận response
Tổng: ~2 giây 🚀
```

→ Tất cả module gửi request **cùng lúc**, không chờ nhau!

## 💻 Code hoàn chỉnh

File: `backend/app/modules/base.py`

```python
from abc import ABC, abstractmethod

class BaseModule(ABC):
    @property
    @abstractmethod
    def name(self) -> str:
        """Tên định danh của module (vd: 'headers', 'cookies')"""
        pass

    @property
    @abstractmethod
    def description(self) -> str:
        """Mô tả ngắn về module"""
        pass

    @abstractmethod
    async def scan(self, url: str, **kwargs) -> list:
        """Thực hiện quét bảo mật theo URL, trả về danh sách findings"""
        pass

    def get_info(self) -> dict:
        return {"name": self.name, "description": self.description}
```

### Giải thích từng phần:

| Thành phần | Loại | Mục đích |
|------------|------|----------|
| `name` | Abstract Property | Tên module — lớp con **bắt buộc** cung cấp |
| `description` | Abstract Property | Mô tả module — lớp con **bắt buộc** cung cấp |
| `scan()` | Abstract Async Method | Logic quét — lớp con **bắt buộc** implement |
| `get_info()` | Method thường | Logic dùng chung — **không cần** override |

## 🔑 Takeaway

1. **ABC** = khuôn mẫu ép buộc lớp con phải implement
2. **`@property` + `@abstractmethod`** = thuộc tính trừu tượng (thứ tự: property trên, abstractmethod dưới)
3. **`async def`** = method bất đồng bộ, giúp chạy song song nhiều I/O operations
4. **Method thường trong ABC** = logic dùng chung cho tất cả lớp con
