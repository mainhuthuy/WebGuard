# Task 2.5 — API: Xuất Báo Cáo (`GET /api/v1/report/{scan_id}/export`)

> **Mục tiêu:** Xây dựng endpoint cho phép người dùng tải xuống báo cáo kết quả quét dưới 2 định dạng: **JSON** (cho máy đọc) và **HTML** (cho người đọc — báo cáo đẹp bằng Jinja2 template).

---

## 🧭 1. Tại sao cần endpoint riêng cho Report Export?

Có bạn sẽ hỏi: *"Task 2.4 đã có `GET /scan/{id}` trả JSON rồi, sao còn cần thêm endpoint?"*

| | `GET /scan/{id}` (Task 2.4) | `GET /report/{id}/export` (Task 2.5) |
|---|---|---|
| **Mục đích** | Frontend render giao diện web | **Tải file xuống** máy tính |
| **Định dạng** | JSON (cấu trúc cho frontend) | JSON hoặc **HTML** (báo cáo đẹp) |
| **HTTP Header** | `Content-Type: application/json` | Có thêm `Content-Disposition: attachment` → Trình duyệt tự mở hộp thoại "Save As..." |
| **Người dùng chính** | Developer, Frontend app | Quản lý bảo mật, Auditor, Khách hàng |
| **Tương tự** | Xem email trong Gmail | Bấm nút "In" để tải file PDF |

## 📚 2. Jinja2 Template Engine — Cỗ máy tạo nội dung động

### Jinja2 là gì?
Jinja2 là thư viện Python giúp tạo **nội dung động** bằng cách kết hợp **template mẫu** (có "chỗ trống") với **dữ liệu thực**:

```
Template + Data → Rendered Output
```

### Ví dụ đơn giản:
```html
<!-- Template (có chỗ trống) -->
<h1>Xin chào {{ name }}!</h1>
<p>Bạn có {{ count }} tin nhắn mới.</p>
```
```python
# Data
{"name": "Huy", "count": 5}
```
```html
<!-- Kết quả render -->
<h1>Xin chào Huy!</h1>
<p>Bạn có 5 tin nhắn mới.</p>
```

### Cú pháp Jinja2 quan trọng:

| Cú pháp | Ý nghĩa | Ví dụ |
|---|---|---|
| `{{ biến }}` | In giá trị biến | `{{ target_url }}` |
| `{% for x in list %}` | Vòng lặp | Lặp qua danh sách findings |
| `{% if condition %}` | Điều kiện | Chỉ hiện scoring nếu có |
| `{{ x \| upper }}` | Filter (biến đổi) | `{{ grade \| upper }}` → "A" |

### Tại sao dùng Jinja2 mà không viết HTML bằng Python string?
```python
# ❌ Cách tệ: Ghép chuỗi HTML bằng tay
html = f"<h1>{target}</h1><ul>"
for f in findings:
    html += f"<li>{f['name']}</li>"  # Không escape → Lỗ hổng XSS!

# ✅ Cách tốt: Dùng Jinja2
template.render(target_url=target, findings=findings)  # Tự escape HTML!
```

Jinja2 tự động **escape HTML** (chuyển `<script>` thành `&lt;script&gt;`), giúp ngăn chặn tấn công XSS.

## 📚 3. `Content-Disposition` Header — Bảo trình duyệt tải file

Khi server trả response với header:
```
Content-Disposition: attachment; filename="webguard_report_abc123.html"
```

Trình duyệt sẽ:
1. **Không** hiển thị nội dung trực tiếp trên trang web.
2. **Mở hộp thoại "Save As..."** để người dùng chọn nơi lưu file.
3. **Đề xuất tên file** là `webguard_report_abc123.html`.

Nếu **không** có header này → Trình duyệt sẽ hiển thị nội dung ngay trên tab (điều này cũng ok cho HTML, nhưng không phải hành vi "xuất báo cáo").

## 📚 4. Query Parameter — Cách truyền tùy chọn cho API

URL: `GET /api/v1/report/{scan_id}/export?format=json`

| Phần | Tên | Ý nghĩa |
|---|---|---|
| `/report/{scan_id}` | Path Parameter | **Bắt buộc** — Xác định tài nguyên cụ thể |
| `?format=json` | Query Parameter | **Tùy chọn** — Tùy biến hành vi của request |

Query Parameter giống như khi bạn gọi trà sữa:
- **Path param** = Chọn món: `"Trà sữa trân châu"` (bắt buộc)
- **Query param** = Tùy chọn thêm: `?size=L&sugar=50%&ice=ít` (tùy chọn, có giá trị mặc định)

Trong code FastAPI:
```python
from enum import Enum

class ExportFormat(str, Enum):
    JSON = "json"
    HTML = "html"

async def export_report(
    scan_id: str,                              # Path parameter (bắt buộc)
    format: ExportFormat = Query(default=ExportFormat.JSON),  # Query parameter (có default)
)
```

Dùng `Enum` thay vì `str` để FastAPI tự validate: chỉ chấp nhận `"json"` hoặc `"html"`, bất kỳ giá trị nào khác → 422 Validation Error.

## 💻 5. Kiến trúc file

```
backend/
├── templates/
│   └── report.html          ← Jinja2 template (giao diện báo cáo)
└── app/
    └── api/v1/
        ├── report.py         ← Endpoint xuất báo cáo
        └── __init__.py       ← Đăng ký report router
```

### Luồng xử lý:
```
Client gọi GET /api/v1/report/{id}/export?format=html
    ↓
1. Kiểm tra scan_id tồn tại trong scan_jobs
    ↓
2. Đọc findings từ scan_jobs, đếm severity_counts
    ↓
3. Nếu format=json → JSONResponse + Content-Disposition
   Nếu format=html → Jinja2 render template → HTMLResponse
    ↓
4. Trình duyệt nhận response → Mở hộp thoại Save As
```

## 🔑 Tóm tắt (Takeaway)

1. **Jinja2** = Template engine: kết hợp mẫu HTML + dữ liệu → nội dung động, tự escape XSS.
2. **`Content-Disposition: attachment`** = Bảo trình duyệt tải file thay vì hiển thị inline.
3. **Query Parameter** = Tùy chọn hành vi API (format, sort, page...), khác với Path Parameter (xác định tài nguyên).
4. **Enum validation** = FastAPI tự reject giá trị không hợp lệ → code sạch hơn.
5. **`response_model=None`** = Khi endpoint trả về `Response` object trực tiếp (không qua Pydantic serialize).
