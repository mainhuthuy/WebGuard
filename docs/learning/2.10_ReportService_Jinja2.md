## 📚 1. Lý thuyết nền tảng

### 1.1 Template Engine là gì? Tại sao nên dùng Jinja2?

Trong phát triển phần mềm, khi cần tạo văn bản động (Dynamic Document) như HTML, email hay báo cáo:
* ❌ **Cách thủ công (String Formatting / f-strings)**: Ghép chuỗi `f"<html><h1>{title}</h1></html>"` rất dễ sinh ra code rối rắm (Spaghetti code), khó bảo trì và **cực kỳ nguy hiểm về bảo mật (lỗ hổng XSS)** nếu dữ liệu quét chứa mã độc.
* ✅ **Template Engine (Jinja2)**: Tách bạch hoàn toàn giữa **giao diện hiển thị (HTML/CSS)** và **dữ liệu nghiệp vụ (Python context)**.

```
┌─────────────────────────┐       ┌────────────────────────┐
│  Dữ liệu quét từ DB     │       │ File template HTML     │
│  (ScanModel + Findings) │       │ (templates/report.html)│
└────────────┬────────────┘       └───────────┬────────────┘
             │                                │
             └───────────────┬────────────────┘
                             │
                             ▼
              ┌─────────────────────────────┐
              │  Jinja2 Environment Engine  │
              │  - autoescape=True (Anti-XSS)│
              │  - template.render(**data)  │
              └──────────────┬──────────────┘
                             │
                             ▼
              ┌─────────────────────────────┐
              │  HTML Report hoàn chỉnh     │
              │  (Cyber Dark Vibe, CSS đầy đủ)
              └─────────────────────────────┘
```

### 1.2 Các thành phần cốt lõi của Jinja2

1. **`FileSystemLoader`**: Bộ nạp chỉ định thư mục chứa các file template (ví dụ `backend/templates/`).
2. **`Environment`**: Cấu hình toàn cục cho Jinja2:
   * `loader`: Xác định nơi tìm file template.
   * `autoescape=True`: **Tối quan trọng trong Security!** Tự động chuyển đổi các ký tự nguy hiểm (`<`, `>`, `&`, `"`, `'`) thành mã HTML entities (`&lt;`, `&gt;`), ngăn chặn kẻ xấu chèn mã JavaScript độc hại vào tiêu đề hoặc nội dung quét (Stored XSS).
3. **Template Context & Rendering**:
   * Phương thức `template.render(**context)` đưa dữ liệu dictionary vào các thẻ `{{ variable }}` và `{% for %}`, `{% if %}` trong file HTML.

### 1.3 Reporting Service Pattern

Trong hệ thống WebGuard, báo cáo không chỉ đơn thuần là in ra kết quả, mà cần thực hiện các phép **tổng hợp số liệu (Aggregation)**:
* **Thống kê phân loại theo mức độ nghiêm trọng (Severity Counts)**: Đếm số lượng lỗ hổng `critical`, `high`, `medium`, `low`.
* **Tính toán thời gian quét (Scan Duration)**: Tính khoảng thời gian `(completed_at - created_at)` theo giây.
* **Thông tin chế độ quét (`mode`)**: báo cáo ghi rõ `quick` hay `full` để người đọc biết phạm vi kiểm tra.
* **Chuẩn hóa đa nguồn dữ liệu**: Tự động nhận diện dữ liệu từ bảng Database (`ScanModel`) hoặc in-memory cache (`scan_jobs`).
* **Hỗ trợ đa định dạng xuất (Multi-format)**:
  * **JSON**: Dành cho máy đọc, tích hợp vào CI/CD pipelines, SIEM hoặc webhook.
  * **HTML**: Báo cáo đồ họa trực quan độc lập (Self-contained CSS) để gửi cho khách hàng hoặc tải về lưu trữ.

## 💻 2. Chi tiết triển khai code

### 2.1 File `backend/app/services/report.py`

```python
class ReportService:
    def __init__(self, templates_dir: Path | None = None) -> None:
        self.templates_dir = templates_dir or TEMPLATES_DIR
        self.jinja_env = Environment(
            loader=FileSystemLoader(str(self.templates_dir)),
            autoescape=True,
        )

    def get_report_data(self, scan_id: str, db: Session | None = None) -> dict[str, Any]:
        """Thu thập dữ liệu đầy đủ từ DB hoặc in-memory fallback, thống kê severity."""
        ...

    def generate_json_report(self, scan_id: str, db: Session | None = None) -> dict[str, Any]:
        """Xuất báo cáo định dạng JSON."""
        return self.get_report_data(scan_id=scan_id, db=db)

    def generate_html_report(self, scan_id: str, db: Session | None = None) -> str:
        """Render báo cáo HTML chuyên nghiệp từ template Jinja2."""
        report_data = self.get_report_data(scan_id=scan_id, db=db)
        template = self.jinja_env.get_template("report.html")
        return template.render(**report_data)

    @staticmethod
    def get_export_filename(scan_id: str, format_ext: str) -> str:
        """Sinh tên file chuẩn: webguard_report_<short_id>.<ext>."""
        short_id = scan_id[:8] if len(scan_id) >= 8 else scan_id
        return f"webguard_report_{short_id}.{format_ext.lower()}"
```

### 2.2 Refactor Router `backend/app/api/v1/report.py`

Tầng Controller giờ đây trở nên vô cùng ngắn gọn, sạch sẽ và tuân thủ đúng Single Responsibility Principle:

```python
@router.get("/{scan_id}/export")
async def export_report(
    scan_id: str,
    format: ExportFormat = Query(default=ExportFormat.JSON),
    db: Session = Depends(get_db),
) -> JSONResponse | HTMLResponse:
    filename = report_service.get_export_filename(scan_id, format.value)

    if format == ExportFormat.JSON:
        data = report_service.generate_json_report(scan_id, db)
        return JSONResponse(content=data, headers={"Content-Disposition": f'attachment; filename="{filename}"'})

    html = report_service.generate_html_report(scan_id, db)
    return HTMLResponse(content=html, headers={"Content-Disposition": f'attachment; filename="{filename}"'})
```

## 🔑 4. Key Takeaways

1. **Jinja2 + `autoescape=True`** là tiêu chuẩn vàng khi tạo HTML động từ dữ liệu quét bảo mật để phòng chống XSS.
2. **Separation of Concerns**: Đưa toàn bộ việc thu thập số liệu, tính toán thời lượng và render vào `ReportService` giúp Router chỉ tập trung vào việc quản lý HTTP headers và response.
3. Báo cáo HTML được thiết kế dạng **Self-contained** (nhúng sẵn toàn bộ CSS nội bộ), người dùng tải file về có thể mở xem ngoại tuyến (offline) ở bất kỳ máy tính nào mà không bị vỡ giao diện!
