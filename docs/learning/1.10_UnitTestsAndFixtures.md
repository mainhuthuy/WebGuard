# Task 1.10 & 1.11 — `Unit Tests` & `Test Fixtures` (`pytest`)

> **Mục tiêu:** Xây dựng hệ thống kiểm thử tự động toàn diện (Unit Tests & Fixtures) bằng `pytest` và `unittest.mock`, đạt chuẩn chạy CI/CD siêu tốc (14/14 tests trong ~2.7 giây).

---

## 📚 Lý thuyết: Tại sao cần Unit Test và Mocking trong Security Scanner?

### 1. Vấn đề khi test bằng mạng thật:
Nếu chạy test bằng cách gửi request thật ra internet:
- **Tốc độ chậm:** Mỗi request mất 1-3 giây → Bộ test 50 test case mất vài phút.
- **Flaky Tests:** Mạng chập chờn hoặc server bên thứ 3 down làm bài test fail dù code của ta không có lỗi.
- **Khó tái hiện ca khó:** Làm sao tìm được một server thật lúc nào cũng cố tình cấu hình sai CORS reflection hay set cookie thiếu cờ để test?

### 2. Sức mạnh của `conftest.py` & `unittest.mock`:
- **`pytest.fixture`:** Định nghĩa các đối tượng giả lập (mock responses, sample data) một nơi, dùng chung cho mọi file test mà không cần import thủ công.
- **`unittest.mock.patch`:** Đánh chặn các cuộc gọi mạng (`httpx.AsyncClient.get`) và ép nó trả về response giả lập ngay tức thì trong RAM (0.001s).
