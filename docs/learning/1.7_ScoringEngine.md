# Task 1.7 — `ScoringEngine` (Thuật toán tính điểm an toàn)

> **Mục tiêu:** Xây dựng bộ công cụ quy đổi danh sách các lỗ hổng (findings) thành điểm số an toàn (0 - 100) và xếp hạng (Grade A+ đến F) theo chuẩn trực quan.

---

## 📚 Lý thuyết: Tại sao cần Scoring Engine?

Một security scanner sau khi quét sẽ phát hiện rất nhiều thông tin kỹ thuật:
- "Thiếu `Content-Security-Policy` (High)"
- "Cookie thiếu cờ `HttpOnly` (High)"
- "Server lộ header `Server: Apache` (Medium)"

Người dùng thông thường hoặc quản trị viên không thể ngồi đọc 20 dòng kỹ thuật để biết ngay trang web của mình **đang ở mức an toàn nào**.

→ **Scoring Engine** giải quyết bài toán này:
```
Danh sách findings  ───►  [ ScoringEngine ]  ───►  Điểm: 45/100 | Grade: F
```

---

## 📚 Cơ chế trừ điểm theo mức độ nghiêm trọng (Severity Penalty)

Mỗi lỗi tìm thấy có một trọng số rủi ro khác nhau. Ta sử dụng thang điểm gốc là **100 điểm**:

| Severity | Điểm trừ | Ý nghĩa rủi ro |
| :--- | :---: | :--- |
| **critical** | **-15** | Lỗ hổng cực kỳ nguy hiểm, có thể dẫn đến lộ session hoặc chiếm quyền tức thì |
| **high** | **-10** | Lỗ hổng nghiêm trọng, dễ bị khai thác (XSS, thiếu HTTPS, CORS wildcard...) |
| **medium** | **-5** | Cấu hình bảo mật yếu, thiếu lớp phòng thủ (Clickjacking, CSRF...) |
| **low** | **-2** | Lộ thông tin phụ, thiếu header bảo vệ cũ |

### Quy tắc chặn biên (Floor Boundary):
Điểm số không được phép âm:
```python
total_score = max(0, total_score)
```

---

## 📚 Bảng xếp hạng (Grade Thresholds)

Dựa trên điểm số cuối cùng, website được xếp hạng:

| Grade | Ngưỡng điểm | Đánh giá |
| :---: | :---: | :--- |
| **A+** | **≥ 95** | **Tuyệt vời**: Cấu hình bảo mật gần như hoàn hảo, áp dụng đầy đủ best practices. |
| **A** | **≥ 85** | **Rất tốt**: Bảo mật mạnh mẽ, chỉ tồn tại một vài sơ suất nhỏ (low/medium). |
| **B** | **≥ 70** | **Khá**: Bảo mật tương đối ổn định, nhưng cần vá một số lỗi mức medium/high. |
| **C** | **≥ 50** | **Trung bình**: Nhiều điểm yếu an ninh, có nguy cơ bị tấn công. |
| **F** | **< 50** | **Kém / Báo động đỏ**: Tích lũy quá nhiều lỗ hổng (tổng điểm trừ > 50). |

> ⚠️ **Một lỗi `critical` KHÔNG tự động làm trượt xuống F.** Điểm chỉ là phép trừ cộng dồn: 1 lỗi critical = −15 → 85 điểm → vẫn là hạng **A**. Thang điểm này chấm theo *số lượng và trọng số tích lũy*, không có luật "một lỗi nghiêm trọng là rớt". Nếu muốn luật đó, phải thêm một trần điểm riêng (vd: có critical thì hạng tối đa là C) — project hiện chưa làm.

## 💻 Cấu trúc Code `ScoringEngine`

```python
class ScoringEngine:
    SEVERITY_SCORES = {
        "critical": 15,
        "high": 10,
        "medium": 5,
        "low": 2
    }

    GRADE_THRESHOLDS = [
        (95, "A+"),
        (85, "A"),
        (70, "B"),
        (50, "C"),
        (0, "F")
    ]

    def calculate(self, findings: list) -> dict:
        total_score = 100
        for finding in findings:
            total_score -= self.SEVERITY_SCORES.get(finding["severity"], 0)
        total_score = max(0, total_score)

        grade = "A+"
        for threshold, grade_letter in self.GRADE_THRESHOLDS:
            if total_score >= threshold:
                grade = grade_letter
                break

        return {
            "score": total_score,
            "grade": grade,
            "total_findings": len(findings)
        }
```

### Ví dụ tính điểm thực tế

Một trang demo thiếu cả 9 security headers (2 high + 5 medium + 2 low) và lộ header `Server` (1 medium):

```
2×10 + 6×5 + 2×2 = 20 + 30 + 4 = 54  →  100 − 54 = 46  →  Hạng F
```

→ Vì mỗi header thiếu là **một finding riêng**, các trang không cấu hình bảo mật nào rất dễ rơi xuống hạng F chỉ do thiếu header. Đó là đặc tính của thuật toán cộng dồn — cần nhớ khi đọc kết quả.

> 📌 **Đối chiếu với project:** code truy cập `finding["severity"]` (không dùng `.get`), nên một finding thiếu khóa `severity` sẽ làm `calculate` ném `KeyError`. Mọi module hiện đều luôn có khóa này; `ScoringEngine` giả định đầu vào hợp lệ. Mức độ lạ (ví dụ `"info"`) không có trong bảng nên bị trừ 0 điểm nhờ `.get(..., 0)` trên bảng điểm. Lưu ý các hạng chỉ gồm **A+, A, B, C, F** — **không có hạng D**.
