> **Mục tiêu:** Xây dựng tầng lưu trữ cơ sở dữ liệu bền vững (Persistence Layer) với SQLite và SQLAlchemy 2.0 ORM, thay thế cho việc lưu tạm thời trên bộ nhớ RAM.

## 🧭 1. Tại sao cần Database & ORM?

### Hạn chế của In-Memory Dictionary (`scan_jobs = {}`):
1. **Mất dữ liệu:** Bất cứ khi nào server khởi động lại (restart/deploy), toàn bộ lịch sử quét sẽ biến mất.
2. **Tràn RAM (Out-Of-Memory):** Nếu quét hàng ngàn trang web với hàng vạn findings, dung lượng RAM của server sẽ cạn kiệt.
3. **Không hỗ trợ truy vấn phức tạp:** Khó lọc theo thời gian, lọc theo mức độ nghiêm trọng (Critical/High), phân trang (Pagination).

### Giải pháp: SQLite + SQLAlchemy ORM
- **SQLite:** Cơ sở dữ liệu dạng file (serverless, zero-configuration). Cực kỳ gọn nhẹ, không cần cài đặt MySQL, PostgreSQL hay Docker phức tạp mà vẫn hỗ trợ chuẩn SQL ACID đầy đủ.
- **SQLAlchemy 2.0 (Type-annotated):** Thư viện ORM số 1 trong hệ sinh thái Python, giúp lập trình viên thao tác với bảng dữ liệu như các Class Python có gợi ý kiểu (Type Hinting) đầy đủ.

## 💻 3. Kiến trúc Cài Đặt (Code Walkthrough)

### 3.1. Cấu hình Engine & Session (`backend/app/db/session.py`)
```python
from collections.abc import Generator
from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, Session, sessionmaker
from app.core import get_settings

class Base(DeclarativeBase):
    """Lớp cha khai báo toàn bộ model."""
    pass

settings = get_settings()

# SQLite cần check_same_thread=False vì FastAPI xử lý đa luồng (multithreaded async)
connect_args = {}
if settings.DB_URL.startswith("sqlite"):
    connect_args["check_same_thread"] = False

engine = create_engine(settings.DB_URL, connect_args=connect_args)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

def get_db() -> Generator[Session, None, None]:
    """Dependency injection cho FastAPI: Tự mở session khi nhận request và tự đóng khi response xong."""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

### 3.2. Cú pháp SQLAlchemy 2.0 (`Mapped` & `mapped_column`)
SQLAlchemy 2.0 giới thiệu cú pháp hiện đại kết hợp hoàn hảo với Type Hinting của Python 3.12:
- Dùng `Mapped[str]` thay cho cú pháp cũ `Column(String)`
- Dùng `cascade="all, delete-orphan"`: Khi một bản ghi `Scan` bị xóa, toàn bộ `findings` liên quan sẽ tự động bị xóa theo (tránh dữ liệu rác mồ côi trong database).

## 🔑 Tóm tắt cốt lõi (Takeaway)

1. **SQLite** là lựa chọn lý tưởng cho các ứng dụng cục bộ/nội bộ hoặc giai đoạn MVP vì tính tiện lợi và gọn nhẹ.
2. **`check_same_thread=False`** là thiết lập bắt buộc khi kết nối SQLite với FastAPI để cho phép nhiều worker thread cùng truy cập database.
3. **Cascade Delete** là cơ chế bảo toàn tính toàn vẹn dữ liệu: Khi xóa cha thì xóa con, không để sót dữ liệu rác.
4. **`get_db()` với `yield`** giúp quản lý vòng đời connection an toàn: Đảm bảo session luôn được giải phóng sau mỗi request dù có lỗi xảy ra hay không.
